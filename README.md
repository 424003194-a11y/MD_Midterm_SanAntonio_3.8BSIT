Community Learning Center Management System

Description
- A console-based Dart application that manages learning resources and participants in a community learning center.

Features
- Add learning resources
- Register participants
- Borrow learning resources
- Return learning resources
- View all registered records
- Check available and borrowed resources
- Validate user inputs
- Prevent duplicate IDs

Technologies
- Dart Programming Language
- Object-Oriented Programming

OOP Concepts
- Classes and Objects
- Constructors and Methods
- Encapsulation
- Inheritance
- Polymorphism
- Abstract Classes
- Mixins
- Lists and Maps

Sample Test Scenarios
1. Valid Resource Registration
   - Add a learning resource with a unique ID.
   - Expected: Resource added successfully.
2. Successful Borrowing
   - Register a participant.
   - Add a resource.
   - Borrow the resource using valid IDs.
   - Expected: Borrowing successful.
3. Invalid Input
   - Enter an invalid menu selection.
   - Expected: Display an error message and return to the menu.
4. Duplicate ID
   - Register an existing resource ID again.
   - Expected: Duplicate ID rejected.

Run Instructions
1. Install Dart SDK.
2. Open the project folder in a terminal.
3. Run: dart main.dart
